# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, assume good faith, criticize ideas rather than people, and do not harass or
exclude others. Maintainers may remove comments, close threads, or block participants whose behavior
makes the project hostile.

## Scope

This applies in issues, pull requests, discussions, and any other project space, and when representing
the project elsewhere.

## Reporting

Report unacceptable behavior privately through GitHub: open a report via Security → Report a
vulnerability and mark it "conduct". Reports are handled by the maintainers, kept confidential, and
answered as promptly as possible. Retaliation against a reporter is itself a violation.

The full Contributor Covenant text, including examples of acceptable and unacceptable behavior and the
enforcement guidelines, is available at the link above and applies as if included here.
